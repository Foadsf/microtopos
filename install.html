Install

MicroTopos 0.8.1 is a single portable program: download it, make it runnable, start it. There is no installer and nothing is written outside your user folder.

Every release is built and self-tested by GitHub Actions from the tagged source. SHA256SUMS.txt lists a checksum for each file.

Linux

  1. Download the file for your processor and open a terminal in the download folder.

  2. Check the download and make it runnable:

    sha256sum -c --ignore-missing SHA256SUMS.txt
chmod +x microtopos-0.8.1-linux-x86_64

  3. Install v4l-utils. MicroTopos uses its v4l2-ctl tool to lock the exposure and switch off in-camera sharpening:

    sudo apt install v4l-utils

  4. Start it:

    ./microtopos-0.8.1-linux-x86_64
Tip
 If the camera is not listed, check that your user may use video devices: groups should include video. If not, run sudo usermod -aG video $USER and log out and back in.

Windows

  1. Download microtopos-0.8.1-windows-x86_64.exe.

  2. Double-click it. The program is not code-signed, so Windows SmartScreen may show "Windows protected your PC". Click More info, then Run anyway.

  3. Allow camera access if Windows asks: Settings › Privacy & security › Camera › Let desktop apps access your camera.

Note
 On Windows and macOS, exposure is set through OpenCV’s camera properties. Whether a given camera honours them depends on its driver; the Camera step shows what the device reports back.

macOS

  1. Download the .zip for your Mac (Apple menu > About This Mac shows Apple M… or Intel), then double-click it to unpack microtopos.app.

  2. The app is not notarised. The first time, right-click it and choose Open, then Open again. If macOS still refuses, run xattr -dr com.apple.quarantine microtopos.app in Terminal.

  3. Allow camera access when asked, or later under System Settings › Privacy & Security › Camera.

Run from source

For development, or on a system without a prebuilt file, run it with uv and Python 3.12 or newer (CI tests 3.12 and 3.13; on 3.11 the Qt bindings abort):

git clone https://github.com/Foadsf/microtopos.git
cd microtopos
uv run microtopos              # the application
uv run microtopos --simulator  # start on the synthetic specimen
uv run microtopos-selftest     # the ground-truth self-test
uv run microtopos-batch REC OUT  # reconstruct every sweep of a recording, deterministically
uv run microtopos-bench        # CPU vs OpenCL focus-measure benchmark on this computer
Note
 On Linux, Qt needs libxcb-cursor0 for its X11 window plugin. If you see "Could not load the Qt platform plugin xcb", run sudo apt install libxcb-cursor0.

Command-line options

Option Effect

--simulator

start on the synthetic specimen; cameras are still listed in step 1

--replay DIR

play back a recording made with Record raw stream or microtopos-record, at its recorded timing (a busy computer skips frames, as with a camera)

--batch REC OUT [options]

analyse every frame of a recording in order and write each sweep’s report to OUT (options: --objective NAME from your objective list, --objectives FILE, --list-objectives, --z-um-per-frame, --direction up/down, --um-per-px)

--bench

measure the focus measure on the CPU and with OpenCL on this computer, with a parity check

-v, --verbose

print the live event log to the console (it is always shown under Diagnostics)

--selftest [--quick] [--gui] [--json FILE]

run the ground-truth self-test and exit; --json writes every row with versions and thresholds

--version

print the version
